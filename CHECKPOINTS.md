# Two weeks: 20 hours, with a mentor

Required workload: **1,200 minutes / 20 hours**. Six 90-minute days plus one 60-minute day per week. Reading, exercises, checkpoints and rehearsal are included—not additional homework. Allow up to five extra hours only for troubleshooting; use the fallback or narrow scope instead of expanding the project.

## Mentor checkpoints

1. **Initial data understanding (day 1):** confirm the authorized Tigers snapshot, selected population, field meanings and intended use. Do not reveal completed discovery counts/answers. If unresolved, work on invented exercises and have the mentor resolve/provide the snapshot rather than lose the first week.
2. **Validation and SQL (day 10):** ask Henry to explain one denominator, one unmatched record and one cardinality risk. Review SQL and tests without supplying the finished result.
3. **Final presentation (day 14):** hear the five-minute briefing as a scouting director. Ask what is safe to conclude, what is still unknown and which action should happen first. Review public contents before a push.

## Required versus stretch

Required: one Tigers affiliate/season and Eastern League peers, three queries, two charts, dictionary, tests, report, reproducible code and presentation. Complete these first.

Stretch only within remaining time: a small additional authorized biography comparison, a static HTML aggregate table, an additional threshold/missingness sensitivity check. Do not add multiple boards, historical ingestion, modeling or a live dashboard.

Required reading budget: seven internal modules at roughly 10 minutes each plus 135 minutes of targeted external reading = about **3 hours 25 minutes**, already inside this schedule. If a link is blocked, use the internal explanation and ask the mentor for access; don't spend the day debugging documentation networking.
