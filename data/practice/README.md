# Invented teaching data only

players.csv and appearances.csv were authored for this starter, without copying real sources. Every ID, name, age, role and game measurement is invented. There are no real player observations, source scouting narratives or third-party dataset excerpts here. These examples can be included as teaching material; the mentor still chooses the repository's code/documentation license before publication.

Players: one row per invented player. Appearances: one row per invented player/game. The role/age fields are labelled practice_* so they cannot be mistaken for measured professional data. A blank practice_hand illustrates missing data. game_id is an invented event label, not an MLB ID.

Use these files to learn file reading, filtering, grouping and one-to-many joins. Do not use their numbers to answer the real project's research questions, demonstrate source feasibility or fill missing real records. Add your own invented bad inputs for tests and label them equally clearly.
