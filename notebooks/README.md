# Optional exploration space

The default workflow is scripts plus SQL; notebooks are optional, not required for this 20-hour scope. The core environment does not install Jupyter or a notebook kernel. If using one, ask the mentor to choose/set up the editor/kernel without expanding the project into infrastructure work.

Use notebooks to inspect or explain your own work, not as the only reproducible pipeline. Restart the kernel and run all cells to expose hidden state. Notebook outputs can embed source-player records or copyrighted scouting text; .ipynb files are ignored by default. Clear and review outputs before deliberately committing an allowed notebook. Do not remove the ignore rule merely to publish a private dataset.
